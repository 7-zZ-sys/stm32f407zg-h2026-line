## 1. 保留与清理

## 2. 八路模块接线

适配照片中的 YAHBOOM `YB-MVX05-V1.0`，不是八根独立输出线，也不是 ADC：

| 模块丝印 | 新工程 STM32 引脚 | 作用 |
|---|---|---|
| 5V | 稳定 5 V | 模块供电 |
| GND | GND | 共地 |
| AD0 | PE0 | 地址最低位 |
| AD1 | PE1 | 地址中间位 |
| AD2 | PE2 | 地址最高位 |
| OUT | PE3 | 选中探头的数字输出 |

按 `AD2 AD1 AD0=000..111` 依次读取 X1..X8。每次选通等待 50 μs，全扫描约 400 μs，加上 GPIO 和中断开销。DWT 等待不关闭中断。

按丝印核对连接器两面的引脚顺序，不按排线颜色猜线。OUT 必须与 MCU 输入电平兼容；先测量高电平，未确认逻辑电平前通过合适的电平转换连接。5 V 供电不等于 OUT 一定为 5 V 或一定为 3.3 V。

当前实车已核对使用 `LREV=0`，因此默认顺序为 X1 在车左、X8 在车右；商品照片朝向不能代替实车安装顺序。默认 `LPOL=1`，仍需核对黑白实测。

官方读取方法：[STM32 数据读取示例](https://www.yahboom.net/public/upload/upload-html/1763523850/Data%20reading.html)。模块是否满足正式比赛对循迹光电器件的要求，应核对你购买的具体版本及赛题原文；软件兼容不等于光源类型已核实。

## 4. 首次运行：先验证数据，再允许运动

1. 导入新工程，编译并烧录 `build/H2026_LineCar.hex`。上电默认不行驶。
2. 架空轮子，JY901S 静止验证完成：遥测第 17 通道为 2、第 18 通道为 200。
3. 模块离地高度按其手册调整，整块放白底：观察通道 21 的原始八位掩码。逐个探头放黑线，确认 X1..X8 能分别改变对应位。
4. 调 `LPOL`，使归一化掩码通道 22 在全白时为 0；黑线在中间时通常只有中心的 1～2 位为 1。数字模块灵敏度靠硬件电位器/高度调节，代码不能恢复灰度原始值。
5. 黑线移到车体左侧：通道 25 应为负；移到右侧应为正。不符合则修改 `LREV`。
6. 确认电机正向与转向符号后发 `LREADY=1`，表示本次上电已核对电平与方向。
7. 先发 `LSPD=120`，再单独发送 `RUN=1`，落地短距离试跑。`STOP` 或 PE5 可停机。每条命令建议带换行。

示例（每行独立发送）：

```text
LPOL=1
LREV=0
LSPD=120
LREADY=1
RUN=1
STOP
```

`LPOL` 或 `LREV` 改动后会撤销 `LREADY`，防止旧确认误用。运行期间除 STOP/ZERO、RUN=0、LAP=0 外，其余串口命令被拒绝，避免手动/无线指令覆盖循迹输出。停止后可以调参，再显式启动。

## 5. 两种运行方式

### RUN=1：连续循迹

当前调参默认 330 mm/s，首次建议改到 120 mm/s。没有单圈终点判定和 20 s 限制，适合调试灰度、左右顺序与 PD。丢线/惯导/时序/堵转保护始终有效。

`LSPD` 是正常循迹速度上限，`LMIN` 是正常弯道最低目标（当前默认 350 mm/s，有效值不超过 LSPD）。偏差和角速度越大，目标越接近 LMIN。例：LSPD=260、LMIN=200 时，正常有效线输入对应 200～260 mm/s；这不是全程恒定 260。全白或持续不可靠图样仍降至 60，短时确认及重获线后的速度恢复可能暂时低于 LMIN；该参数也不保证实际轮速瞬间达到目标。LMIN 只影响 RUN，LAP 仍由 LLAP/LCURVE 控制。

针对 LSPD=260、弯道约 160、一圈约 33 s 的现象，可先保持原 PD、LSPD=260，单独把 LMIN 试到 180，整圈稳定且无效事件不增加后再试 200。提速是否可行取决于实际纠偏能力，不能用速度下限掩盖冲线。按约 6142 mm 赛道估算，33 s 的平均速度约 186 mm/s；全程 260 的理想用时约 23.6 s，20 s 则要求平均至少约 307 mm/s，还未计入起停耗时。

左偏差为负，输出正角速度使车左转；右偏差为正时反之。连续命中有效；另允许命中集中在最多四路探头内、仅缺中间一路的两组图样，例如十进制 40（00101000）、26（00011010）。按实际命中重心算偏差，不修改原始/归一化掩码，不将缺口补成横线。全白、跨距过大、两个及以上缺口或三组命中仍无效，不把相隔较远的两组平均成“居中”。

非零无效图样先进行最多 20 ms 的确认：维持上次可靠转向，速度不高于此前目标、当前模式正常弯道下限和 300 mm/s 三者中的最低值，确认期间不加速，也不参与横线识别。达到 20 ms 仍无可靠图样则降为 60 mm/s，沿上次偏差方向尝试恢复；全白跳过确认，立即降至 60。两种情况均从第一次无效开始计时，达到 120 ms 仍无可靠线就锁存停车。改变无效掩码不重置该计时；重获有效线才结束本次事件。

RUN 中，包含中间两路的连续三路或更多压线图样仍按重心纠偏，并参与弯道减速。只有 LAP 尚未离开起点或已满足返程条件时，宽线才保持上一偏差，避免把普通弯道误作横线而延迟转向。

速度恢复采用不对称处理：需要降速时立即降低循迹目标值，至少保持 100 ms，之后每秒最多增加 160 mm/s；若再次需要降速，重新计时。实际轮速仍由原底盘运动规划和速度 PI 执行，因此目标降速不等于车轮瞬间降速。短时非零图样确认后从受限速度恢复；全白或确认失败后从 60 mm/s 恢复。RUN 和 LAP 均使用此策略。

若 260 mm/s 时直线摆动、弯道冲线，先用固定 180 mm/s 验证。以 `LKP=160`、`LKD=3` 为基准，直线反复摆动时可先单独试 `LKD=4`；仍有持续摆动再单独试 `LKP=140`。每次必须 STOP 后设置再 RUN，不要同时改速度和 PD。先使直线、弯道都稳定，再按 180→220→260 逐级提速；以上是试调起点，需实车验证。

### LAP=1：H 题顺时针单圈启停

默认直道 400 mm/s、弯道最低目标 350 mm/s，均为待实车调试的初值。先通过连续循迹测试再使用。

程序先忽略起步横线；看到窄线且走出 250 mm 后才进入返程检测。累计里程至少 5000 mm、累计实测顺时针转角至少 300°，才允许识别 A 点启停线。符合条件的宽线持续至少 20 ms 后进入定点停车流程。

圈长约 6142 mm，但程序不靠“走够一个固定长度”宣布完成；真正停车需要返程横线。里程只是屏蔽起点和提前减速的辅助信息。累计里程超过 7500 mm 仍未完成、时间超过 20 s、持续不前进等均报告故障。

里程达到 5900 mm 后降到 100 mm/s 等待横线。这个阈值会受轮径/打滑误差影响，必须实测。到达目标后撤销 PWM，并观察轮速低于 20 mm/s 持续 100 ms 才置 DONE，计时冻结；这不是外部位置误差测量。

默认 `LSTOP=0`，以探头排中心作为车体中心轴线上的唯一测试点，横线确认后立即进入停车。若指定测试点在探头后方，则按实际距离设置正 `LSTOP`；还需校正横线宽度、消抖距离和实际惯性滑行。不能只凭设置 LSTOP 宣称达到 2 cm。

5 cm 启停横线不一定能盖住 8 路探头，默认 `LMARK=3`，且要求两个中心探头命中、探头组连续。把板放到实际 A 线读取掩码后再选阈值，不能假定“8 路全黑才算终点”。

实体 START 默认等价于 LAP=1；`LMODE=0` 改为低速 RUN 模式，`LMODE=1` 恢复单圈。启动时已经按住 START 不会自动运行，需松开后重按。

## 7. 遥测

VOFA FireWater，115200/8N1，默认两路镜像；原 1～20 通道顺序保留。

| 通道 | 内容 |
|---|---|
| 1～4 / 5～8 / 9～12 | 四轮目标速度 / 实测速度 / PWM |
| 13～16 | 航向目标、实测航向、实测角速度、控制角速度，乘 100 |
| 17～20 | JY901S 状态、校准样本数、航向/转向环启用、IMU 故障累计 |
| 21 | 原始 OUT 掩码：bit0=X1，bit7=X8 |
| 22 | 归一化黑线掩码：bit0=车左，bit7=车右 |
| 23 | 状态：0 待机、1 循迹、2 停车确认、3 完成、4 故障 |
| 24 | 故障码，见下表 |
| 25 | 归一化横向偏差 ×1000：负左、正右 |
| 26 / 27 / 28 | 本次里程 mm / 本次用时 ms / 累计转角 deg×100 |
| 29 / 30 | LREADY / 底盘停机锁存 |
| 31 | 循迹线速度目标 mm/s，进入底盘运动整形前；不是单轮目标速度 |
| 32 / 33 | IMU 最近故障原因 / UART 错误位掩码，见下表 |
| 34 | 速度原因：0 正常、1 偏差/角速度降速、2 全白或持续无效后找线、3 保持低速/恢复速度、4 单圈终点接近、5 停车补偿限速、6 停车/故障、7 非零无效图样短时确认 |
| 35 | 本次运行无效探头事件累计；连续无效算一次，重获线后再次无效才加一 |
| 36 | 最近一次无效时的归一化掩码，重获线后保留；0 为全白，非零为超出局部单缺口容错范围的多组命中 |

以上按 CSV 第一个数为通道 1 计数；若 VOFA 界面从 0 编号，则对应编号减 1。

第 35/36 列在显式启动或 LRESET 时清零，可捕获被默认 100 ms 遥测间隔漏掉的短事件。若第 31 列骤降，可先使用 RUN、LSPD=120、LMIN=140：此时正常有效线输入的快慢速度均为 120 mm/s，转弯本身不调低线速度；若仍降至 60 且第 35 列增加，说明触发无效线处理。第 36 列为 0 时检查探头覆盖/高度/灵敏度及采样；非零时检查是否有中间探头漏检而分成多组。2026-10-29 根据实测 40/26 增加有限的局部单缺口容错，这两个掩码不再增加无效事件计数，但仍需检查探头灵敏度是否一致。第 34 列为 3 表示速度恢复过程，不能据此排除之前发生过短时无效，应同时看累计计数。

短时非零图样确认仍会增加第 35 列并更新第 36 列，即使它没有造成目标降到 60。原因 2、7 可能只持续 10～20 ms，被默认 100 ms 遥测漏掉；绿色最近无效掩码是保留值，并非“当前持续无效”。截图有纵轴仍应以游标或原始 CSV 的准确整数解码探头位，不按曲线高度猜某个具体图样。新版使用原来的 LSPD=260、LMIN=180 和同一套 PD 对照复测；目标是减少短事件引起的速度下探，不能据此宣称传感器误检或电气问题已经解决。

IMU 状态（第 17 列）：0 未就绪/初始化，1 静止校准，2 就绪，3 故障。0、3 循环表示初始化或通信反复失败；1、3 循环则说明已经进入校准，随后遇到通信/数据故障，并非仅仅静止条件不合格。车体晃动或倾斜导致静止校准不通过通常保持 1。第 32/33 列在自动重试时保留上次故障，重新校准就绪后归零；第 20 列故障计数保留。

| 第 32 列 | IMU 故障含义 |
|---|---|
| 0 | 无故障 |
| 1 | 扫描波特率未收到有效配置应答，检查模块供电、共地和双向 TX/RX |
| 2 | 读取六轴算法配置失败 |
| 3 | 配置读回失败或值不一致 |
| 4 | 主控 UART 发送失败 |
| 5 | UART 接收错误；第 33 列：1 校验、2 噪声、4 帧错误、8 溢出、16 DMA 错误，可按位组合 |
| 6 | 软件接收队列溢出 |
| 7 | 接收传输启动失败 |
| 8 / 9 / 10 | 角度超时 / 角速度超时 / 有效配对数据超时 |

初始化同地址读回最多尝试 3 次。重新启动数据接收后，尚未到达的首批数据允许等待 500 ms。校准阶段数据间断超过 50 ms 会清零静止样本、保持状态 1；数据恢复后重新累计至少 200 个配对样本且跨度至少 1990 ms，不能跨间断直接就绪。校准期间任一类数据持续缺失超过 500 ms 才报超时故障；UART 错误、队列溢出仍立即故障。进入状态 2 后，各类数据依然执行 50 ms 新鲜度保护。配置不变时不写模块 Flash。可对照“冷上电”和“保持 IMU 供电、仅按主控复位”两次第 32 列读数，区分启动时序现象；这不能代替供电和串口实测。

故障码：0 正常；1 未确认 LREADY；2 IMU 失效；3 起步无可靠线；4 持续丢线；5 控制时序异常；6 单圈超时；7 里程异常；8 堵转/无进展；9 停车确认超时；10 用户停车。完成后第 27 通道冻结，重启任务时归零。

循迹时第 13 通道随当前航向更新，转向根据灰度 PD 和陀螺仪角速度反馈，不把旧的期望航向累计误差带入循迹。手动 V/W/HEAD 模式仍保留原航向环。
