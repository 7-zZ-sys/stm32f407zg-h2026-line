# H2026_LineCar 接线表

适用主控：STM32F407ZGT6，LQFP144。整理日期：2026-10-29。

本表摘自原实车维护清单，并仅列出当前独立循迹工程使用的外设。上传整理未改接线、GPIO 或外设通道；以本工程 `H2026_LineCar.ioc` 和实际硬件为准。

## 四轮电机与编码器

| 电机 | 位置 | PWM | IN1 / IN2 | 编码器 A / B | 编码器定时器 |
|---|---|---|---|---|---|
| A | 左前 | PA6 / TIM3_CH1 | PC0 / PC1 | PA15 / PB3 | TIM2_CH1 / CH2 |
| B | 左后 | PA7 / TIM3_CH2 | PC2 / PC3 | PD12 / PD13 | TIM4_CH1 / CH2 |
| C | 右前 | PB0 / TIM3_CH3 | PB8 / PB9 | PE9 / PE11 | TIM1_CH1 / CH2 |
| D | 右后 | PB1 / TIM3_CH4 | PC10 / PC11 | PC6 / PC7 | TIM8_CH1 / CH2 |

正 PWM 对应的 IN1/IN2：A 为 1/0，B 为 0/1，C 为 0/1，D 为 1/0；负 PWM 反向。编码器符号和实车电机安装方向仍需架空验证。

TIM3 PWM 频率 10 kHz，占空比指令量程 ±8399；TIM7 触发 10 ms 控制周期，TIM6 提供 HAL 时基。保留轮径 65.5 mm、有效轮距 250 mm、每轮每圈 1320 编码器计数标定。

## 八路 MUX 数字循迹模块

| 模块引脚 | STM32 / 电源 | 说明 |
|---|---|---|
| AD0 | PE0 | 地址最低位 |
| AD1 | PE1 | 地址中间位 |
| AD2 | PE2 | 地址最高位 |
| OUT | PE3 | 数字电平输入；不是 ADC |
| 5V | 稳定 5 V | 模块供电，按具体型号核对 |
| GND | GND | 共信号地 |

地址 `AD2 AD1 AD0=000..111` 对应 X1..X8，每次切换后至少等待 50 μs。OUT 必须满足 MCU 输入电平要求；5 V 模块供电不代表输出电平已经确认。正式比赛还需核对具体产品的光源类型是否满足红外光电限制。

当前实车调参为 LPOL=1、LREV=0，即黑线高电平，X1 在车左、X8 在车右；更换安装方向后重新验证。

## 启停、惯导和串口

| 功能 | STM32 引脚 / 连接 | 说明 |
|---|---|---|
| START | PE4 → 按键 → GND | 内部上拉、低电平有效、20 ms 消抖；默认启动 LAP，LMODE=0 改为 RUN |
| STOP | PE5 → 按键 → GND | 内部上拉、低电平有效，优先锁存停车 |
| JY901S TX | PB11 / USART3_RX | DMA1_Stream1 / Channel4 循环接收 |
| JY901S RX | PB10 / USART3_TX | 配置/回读通道必须连接 |
| JY901S VCC / GND | 稳定 3.3 V / GND | 模块水平牢固安装，避开大电流回路 |
| 有线调参 TX / RX | PA9 / PA10 | USART1；MCU TX 接适配器 RX，MCU RX 接适配器 TX |
| 可选无线桥 TX / RX | PD5 / PD6 | USART2；与有线调参保持来源隔离 |
| SWDIO / SWCLK | PA13 / PA14 | 下载与调试 |
| 外部高速晶振 | PH0 / PH1 | HSE 输入 / 输出 |

串口使用 115200/8N1、3.3 V 逻辑并共地。JY901S 配置为 100 Hz、六轴模式，仅输出角度和角速度；上电静止验证完成后，VOFA 第 17 列为 2、第 18 列为 200。未就绪和运行中数据过期会阻止运动或锁存停车。

本工程不配置原 TIM5 云台输出；PA0/PA1 不用于舵机。原 PB12～PB15 不再用于循迹。接线前核对开发板是否对 PE0～PE5 等引脚有板载负载。
